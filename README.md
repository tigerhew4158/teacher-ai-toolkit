# 阿虎老师AI工具包订购网站 MVP v1.3

这是可直接打开测试的前端原型版，已加入手机版与电脑版响应式操作界面。

## 测试方式
1. 解压 ZIP
2. 打开 `index.html`
3. 点击「一键体验老师账号」
4. 到「工具包」订购工具包
5. 上传任意图片当付款截图
6. 进入「后台」，密码：`admin123`
7. 在订单管理点击「确认付款并开通」
8. 回到会员中心进入工具测试

## v1.3 新增：试用申请流程

- 老师必须先注册、填写电邮与手机号码，并完成登入，才能申请试用。
- 每位老师只能申请一次试用。
- 老师申请后，后台会出现「试用审核」记录，并产生一条后台即时通知。
- 管理员批准后，系统会开通 7 天试用权限。
- 系统会模拟发送电邮给申请者；老师可在会员中心看到「系统电邮通知」。
- 管理员也可以拒绝试用申请，系统同样会模拟发送结果通知。

测试流程：
1. 注册老师账号，必须填电邮和手机。
2. 登入后到「工具包」点击「申请试用」。
3. 进入后台，密码 admin123。
4. 点击「试用审核」→「批准并开通试用」。
5. 回到老师会员中心，即可看到已开通的试用工具包和系统电邮通知。
